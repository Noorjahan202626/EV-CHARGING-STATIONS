## How the Asset Is Integrated
- The video is loaded in `src/components/Landing/RealWorldEVVisual.jsx` via a standard `<video>` tag with `autoPlay`, `muted`, `loop`, and `playsInline` attributes.
- A `poster` attribute points to the fallback image so the hero section shows a static preview while the video buffers.
- CSS rules in `src/styles/landing.css` (`.lp-ev-video`, `.lp-ev-frame`, etc.) ensure the video is responsive and respects the site’s white‑and‑emerald theme.
- Motion‑for‑React animations are applied to the surrounding hero content but **not** to the video itself, keeping performance high.

## Updating / Replacing the Video
If you need to swap the video for a different one:
1. **Upload** the new MP4 to a public CDN (or place it in the project’s `public/` folder).
2. **Edit** the `src` attribute in `RealWorldEVVisual.jsx` to point to the new URL or local path, e.g.:
   ```jsx
   <video
     src="/my-new-video.mp4"
     poster="/my-new-poster.jpg"
     ...
   />
   ```
3. (Optional) Update the poster image URL similarly.
4. Ensure the new asset complies with licensing for commercial use.
5. Re‑run the dev server or rebuild the project to see the changes.
